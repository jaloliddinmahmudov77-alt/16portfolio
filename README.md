# 16portfolio

16-maktab o'quvchilarining portfolio sayti: 1–11-sinflar, "A" va "B" guruhlar, o'quvchi rasmlari va ma'lumotlari.

## Ishga tushirish

`index.html` ni brauzerda oching yoki papkada lokal server ishga tushiring:

```bash
python -m http.server 8016
```

va http://localhost:8016 manzilini oching.

## Tuzilishi

- `index.html`, `style.css`, `app.js` — asosiy sahifa
- `admin.html`, `admin.css`, `admin.js` — boshqaruv paneli (o'quvchi qo'shish, tahrirlash, o'chirish)
- `store.js` — ma'lumotlarni saqlash
- `data.js` — o'quvchilar ro'yxati
- `rasmlar/` — o'quvchilar rasmlari
- `maktab.webp` — orqa fon rasmi
